## 세션 후 집계

`bun run summary`를 돌려 아래를 옮겨 적는다.

| 항목 | 값 |
| --- | --- |
| 선택 실행 | ___ 회 (주입 실패 ___ 회) |
| 되돌리기율 | ___ % |
| 놓침 | ___ 회 · ___ % |
| 반응시간 중앙 | ___ ms (표본 ___ 회) |
| 머무름 연타 | ___ 회 |
| 눌림 시간 중앙 | ___ ms |
| 주사 간격 | ___ ms → ___ ms (___ 회 조정) |
| 정지 시간 | ___ 초 |
| 최초 설정 시간 | ___ 초 (세션 A만) |

> 반응시간 표본 수가 선택 실행 수보다 적은 것은 정상이다. 머무름 연타는 커서를
> 기다린 것이 아니라 표본에서 뺀다.
